# hermes-skill-bouquet-layout

Скилл [Hermes Agent](https://hermes-agent.nousresearch.com/docs) для раскладки букета: из одного фото букета/цветочной композиции собирает брендированный макет PNG 2048×2048 — букет слева, компоненты по секциям справа, палитра и структура снизу. Сделан для цветочной мастерской «Кот и Клевер» (clovercat.ru), но бренд и тексты меняются в `spec.json` и `scripts/compose.py`.

## Какие задачи решает

- **Разбор букета на составные части**: по фото определяются главные цветы (3–5), текстурные акценты (упаковка, корзина, декор — 2–3), зелень (2–3) и воздушный элемент (гипсофила и т.п.).
- **Палитра букета**: до 7 доминирующих цветов, извлечённых из фото (только непрозрачные пиксели выреза, буст насыщенных кластеров, фильтр разнообразия — наивный quantize по всей картинке не используется).
- **Структура и форма**: миниатюра букета с 5 характеристиками — Вертикаль, Объём, Плотность, Текстура, Движение.
- **Брендированный макет**: единый PNG 2048×2048 в фирменном стиле (тёмный зелёно-графитовый фон, кремовый текст, шрифт Cormorant Garamond), готовый для соцсетей и печати.

## Что делает и как

Пайплайн (подробно — в [SKILL.md](SKILL.md)):

1. **Анализ фото** — vision-модель агента определяет компоненты букета по секциям, с приближенными кропами для точной идентификации видов цветов.
2. **Вырезание букета с фона** — `scripts/cutout_palette.py`: [rembg](https://github.com/danielgatis/rembg) (модель u2net) снимает фон, обрезка по альфа-каналу; из того же прохода извлекается палитра (PIL quantize по непрозрачным пикселям).
3. **Генерация компонентов** — каждый компонент (отдельный цветок, упаковка, зелень) генерируется как студийное предметное фото на тёмном фоне через скилл `image-generation` (генеративная image-модель, референсом служит исходное фото букета).
4. **Вырезание компонентов** — rembg + кроп по альфа-каналу для каждого сгенерированного кадра.
5. **Сборка макета** — `scripts/compose.py` (PIL/Pillow): сетка макета, шапка с брендом, секции компонентов с подписями, круги палитры с обводкой, блок структуры. Вход — `spec.json`, выход — PNG 2048×2048.
6. **Контроль качества** — vision-проверки на каждом этапе (вырез букета, лист компонентов 3×3, лист вырезок, итоговый макет).

Технологии: Python 3, Pillow (сборка и палитра), rembg/u2net (удаление фона), vision + image-генерация Hermes Agent, переменный шрифт Cormorant Garamond (OFL, включён в репозиторий).

## Установка на чистый Mac

### 1. Скилл в Hermes Agent

```bash
mkdir -p ~/.hermes/skills/creative
git clone https://github.com/vokasug/hermes-skill-bouquet-layout ~/.hermes/skills/creative/bouquet-layout
```

### 2. Python-окружение (rembg + Pillow)

```bash
cd ~/.hermes/skills/creative/bouquet-layout
uv venv venv
uv pip install --python venv/bin/python 'rembg[cpu]' pillow
```

Все скрипты запускать питоном из этого venv: `venv/bin/python`.

### 3. Модель rembg

При первом запуске `cutout_palette.py` модель u2net (~1 ГБ) скачается автоматически в `~/.rembg/models/`. Отдельных действий не требуется — просто дайте первому прогону доступ в интернет.

### 4. Шрифты

Уже в репозитории (`fonts/`, Cormorant Garamond variable, лицензия OFL). Ничего ставить не нужно.

### 5. Скилл image-generation

Компоненты букета генерируются через скилл `image-generation` — он должен быть установлен и настроен (провайдер image-генерации с ключом API). Раскладка без него соберётся только из вырезанных фрагментов исходного фото.

### 6. Проверка

Самопроверка сборщика без генерации (строит макет на заглушках):

```bash
cd ~/.hermes/skills/creative/bouquet-layout
venv/bin/python scripts/selftest_gen.py && venv/bin/python scripts/compose.py --spec selftest/spec.json --output selftest/test_layout.png
```

Должен получиться `selftest/test_layout.png` 2048×2048 со всеми секциями.

## Использование

Основной путь — через агента: пришлите фото букета и попросите раскладку («разложи букет и палитру»). Агент загрузит скилл и пройдёт весь пайплайн сам.

Ручной запуск сборщика из готового spec.json (схема — в [SKILL.md](SKILL.md)):

```bash
venv/bin/python scripts/compose.py --spec run1/spec.json --output run1/final.png
```

Вырезание букета и палитра из фото:

```bash
venv/bin/python scripts/cutout_palette.py --input photo.jpg --cutout bouquet_cut.png --palette-json palette.json
```

## Настройка под себя

- **Бренд**: название, подпись и цвета зашиты в `scripts/compose.py` (фон (22,32,30), текст #FAF5E9, акцент teal); название и подпись также задаются в `spec.json` (`brand.name`, `brand.tagline`).
- **Рабочие прогоны**: каждый прогон — отдельная папка `runN/` рядом со скриптами (пути в spec.json относительные). Папки `run*/`, `selftest/` и `venv/` в репозиторий не входят (см. `.gitignore`).
- **Лимиты макета**: ≤10 компонентов (4+3+3), палитра ≤7 кругов.
