# Раскладка букета («Кот и Клевер»)

Из одного фото букета/композиции собирает брендированную раскладку PNG 2048×2048:
букет слева, компоненты по секциям справа, палитра и структура снизу. Итог —
ОДНО изображение, не видео.

## When to Use / Когда применять

- пользователь прислал фото букета/цветочной композиции и просит «раскладку»,
  «разбор на составные части», «разложи букет и палитру», «как в том видео».
- Первым действием — загрузить ещё и скилл `image-generation`: компоненты
  генерируются только через него.
- Не применять к: генерации самого букета с нуля, видео-раскладкам.

## Инструментарий (уже установлен, не пересоздавать)

- Рабочая папка `/Users/alexander/bouquet-layout/`:
  - `compose.py` — сборщик макета (PIL), вход spec.json, выход PNG 2048×2048;
  - `cutout_palette.py` — вырезание с фона (rembg) + извлечение палитры;
  - `fonts/` — Cormorant Garamond variable (фирменный шрифт с clovercat.ru);
  - `venv/` — python с rembg+pillow (запускать `venv/bin/python`);
  - `selftest_gen.py` + `selftest/` — самопроверка сборщика на заглушках;
  - `run1/` — эталонный прогон: spec.json, вырезки, итоговый макет.
- rembg-модель (~1 ГБ) уже скачана в `~/.rembg/models/`.

## Бренд (clovercat.ru, зашит в compose.py)

- Название «Кот и Клевер», подпись «МАСТЕРСКАЯ ЦВЕТОВ И ДЕКОРА · МОСКВА».
- Фон тёмный зелёно-графитовый (22,32,30) — адаптация фирменного #0E2A26 под
  тёмный макет; текст кремовый #FAF5E9; акцент teal.

## Анатомия макета (по референс-видео заказчика)

- Шапка слева вверху: бренд + подпись.
- Левая колонка: букет крупно, вырезанный, без фона.
- Правая колонка, секции сверху вниз: ГЛАВНЫЕ ЦВЕТЫ (3–5 шт), ТЕКСТУРНЫЕ АКЦЕНТЫ
  (2–3: упаковка, корзина, декор), ЗЕЛЕНЬ (2–3); по 3 в ряд.
- Низ слева: ВОЗДУШНЫЙ ЭЛЕМЕНТ (1 широкое фото) + ПАЛИТРА (7 кругов из фото).
- Низ справа: СТРУКТУРА И ФОРМА — миниатюра букета + 5 подписей с линиями:
  Вертикаль, Объём, Плотность, Текстура, Движение (с уточнениями под букет).

## Пайплайн (порядок обязателен)

1. Новый прогон = новая папка `runN/` в bouquet-layout/. Прогоны не смешивать.
2. Анализ фото (vision): компоненты по секциям с названиями и цветами,
   воздушный элемент, 5 характеристик структуры. Композиция в корзине/кашпо →
   корзина и её декор идут в «Текстурные акценты».
   Виды цветов определять приближенными vision-кропами (`region` вокруг
   сомнительного цветка), а не по общему плану — иначе подписи будут неточными.
   Неуверенную идентификацию честно отметить пользователю в финале
   (подпись правится в spec.json без перегенерации).
3. Вырезание + палитра — ИЗ ПОЛНОГО ФОТО, без кропов: букет должен быть
   целиком, включая вазу/кашпо/корзину — сосуд часть образа. Сосуд также
   генерируется отдельным компонентом в «Текстурные акценты».
   `venv/bin/python cutout_palette.py --input <фото> --cutout runN/bouquet_cut.png --palette-json runN/palette.json`
   Затем vision-проверка выреза: сосуд целиком (стекло читается, без остатков
   фона), ручки/цепочка/вылетающая зелень целы.
4. Генерация компонентов (скилл image-generation): по одному фото на компонент,
   все параллельно (до 10), качество medium, 1:1,
   `--reference <исходное фото> --reference-name "букет"`, slug `bouquet-<N>`.
   Стилевой блок промпта дословно:
   «Профессиональное студийное предметное фото для цветочной раскладки.
   Однотонный очень тёмный зелёно-графитовый фон (#16201E), мягкий направленный
   студийный свет, фотореализм, высокая детализация. Строго один предмет
   в кадре, целиком, ничего лишнего, без текста.»
   + «На референсном фото — <что за композиция>. Изобразить ОТДЕЛЬНО:
   <компонент, цвет, где он на референсе, ракурс>».
   Критерий: все `0N_имя.png` в `result-image-generation/YYYY-MM-DD_bouquet-<N>/`.
5. Контрольный лист 3×3 (PIL) → vision: каждый кадр соответствует компоненту,
   один предмет, тёмный фон, нет текста. Брак — перегенерировать точечно.
6. rembg-вырезание каждого компонента + кроп по альфа-каналу (цикл как в run1).
   Обязательно: фон сгенерированных картинок не совпадает с фоном макета,
   без вырезания видны прямоугольники. Лист вырезок → vision (тонкие части:
   гипсофила, цепочка — rembg их не съел).
7. spec.json (схема ниже) → `python3 compose.py --spec runN/spec.json --output runN/final.png`.
8. Vision-проверка итога: нет наложений и обрезки, палитра целиком в кадре,
   подписи читаются. При проблемах — правка compose.py/спеки и пересборка.
9. Доставка: финальное сообщение с `MEDIA:<путь>`. Промежуточные файлы не слать
   (компоненты уже внутри макета), если пользователь не просил.

## spec.json — схема

```json
{
  "brand": {"name": "Кот и Клевер", "tagline": "МАСТЕРСКАЯ ЦВЕТОВ И ДЕКОРА · МОСКВА"},
  "bouquet": "runN/bouquet_cut.png",
  "sections": [{"title": "Главные цветы", "items": [{"img": "...", "label": "Гербера", "sublabel": "малиновая"}]}],
  "airy": {"title": "Воздушный элемент", "img": "...", "label": "Гипсофила", "sublabel": "белая"},
  "palette": ["#rrggbb", "...до 7"],
  "structure": {"img": "runN/bouquet_cut.png", "notes": ["Вертикаль|ручки-кольца", "...всего 5"]}
}
```
Разделитель «|» в notes: слева термин, справа уточнение (уйдёт курсивом в скобки).

## Подводные камни

- venv живёт в bouquet-layout/venv (НЕ в scratch — там чистка через 24 ч
  простоя). Если сломан: `uv venv venv && uv pip install --python venv/bin/python 'rembg[cpu]' pillow`.
- Палитру нельзя считать наивным quantize по всей картинке: прозрачный фон и
  крупная обёртка съедают цветы. cutout_palette.py берёт только непрозрачные
  пиксели + буст насыщенных кластеров + фильтр разнообразия — не упрощать.
- Тёмные ягодно-пурпурные цветы (чёрная калла и т.п.) похожи на тени: порог
  отсечки в cutout_palette.py уже понижен до max<30 — не поднимать, иначе
  акцентный цвет пропадает из палитры. Круги палитры рисуются с кольцом-
  обводкой: тёмный цвет без неё сливается с фоном макета.
- Поля макета — 80px со ВСЕХ сторон, включая низ: палитра исторически
  упиралась в нижний край. После правок compose.py проверять программно:
  крайний контент-пиксель снизу должен быть на y = 2048-1-80 (см. «Проверка»).
- Пустой `saved: []` при генерации — транзиентный глюк провайдера: повторить
  ту же команду, не переписывая промпт.
- rembg иногда съедает тонкие части (гипсофила, цепочка): проверять лист
  вырезок; при потере — брать кадр с запасом по краям или оставить
  прямоугольник (его тёмный фон почти незаметен на макете).
- Лимиты макета: ≤10 компонентов (4+3+3), палитра ≤7 кругов. Больше —
  сокращать список, а не теснить сетку.
- Тёмное атмосферное исходное фото даёт приглушённую палитру — это норма,
  не «чинить». Простой фон у фото = чище вырез, но не требование.

## Проверка

- Итог 2048×2048, все секции на месте (сверить с «Анатомией»), vision-чек пройден.
- Поля равные со всех сторон (80px): проверка нижнего поля программно —
  сканирование снизу вверх первого ряда, отличающегося от фона (22,32,30);
  отступ должен быть ~79–80px.
- Самопроверка сборщика без генерации:
  `python3 selftest_gen.py && python3 compose.py --spec selftest/spec.json --output selftest/test_layout.png`
